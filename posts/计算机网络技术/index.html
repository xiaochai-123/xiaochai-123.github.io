历史

从世界上第一台计算机ENIAC开始，随着计算机的产生，人们就开始想能不能把计算机与计算机之间进行连接，形成一个网络呢？于是美国国防部做了世界上最早的分组交换网络——ARPANET(阿帕网)，如下图所示

除此之外，人类还有多个网络项目，但最终美国的ARPANET胜出，成为今天的互联网

计算机网络的定义

以能够相互共享资源的方式互联起来的自治计算机系统的集合。这一定义可以从以下4个方面来理解:

  1. 计算机网络建立的主要目的是实现资源共享
  2. 互联的计算机是分布在不同地理位置的多台独立的“自治计算机”
  3. 连网计算机之间的通信必须遵守共同的网络协议
  4. 互联计算机之间的连接需要有一条通道,即由传输介质实现物理互联

互联网的组织结构

这里的基础概念：

  • ISP(Internet Service Provider):互联网服务提供商

  • 节点(node):计算机、交换机、路由器等构成网络的硬件都可以称为网络中的节点

  • 主机(host):通过网络为其它机器提供服务的计算机,也称服务器

  • 客户端(client):指从主机处获得服务的计算机,也称为终端

上图中的主干网，校园网等就是指ISP（主干ISP，地区ISP，本地ISP再到公司，个人用户等）

这里的基础概念：

  • 报文(message):网络中交换与传输的数据单元

  • 分组(packet):为了从源端系统向目的端系统发送一个报文,源端将长报文划分为较小 的数据块,称为分组

  • 比特(bit):用小写字母b表示,1b表示一个二进制位,0或1

    字节(byte):用大写字母B表示,1B表示一个字节

    $1\ B = 8\ bit$

    $1\ KB = 2^{10}\ B$

    $1\ MB = 2^{10}\ KB = 2^{20}\ B$

    $1\ GB = 2^{10}\ MB = 2^{20}\ KB = 2^{30}\ B$

    $1\ TB = 2^{10}\ GB = 2^{20}\ MB = 2^{30}\ KB = 2^{40}\ B$

    传输速率：每秒钟传输多少个比特（bit/s、b/s、bps，即 bit per second）

    $1\ B = 8\ bit$

    $1\ Kb/s = 10^3\ b/s$

    $1\ Mb/s = 10^3\ Kb/s = 10^6\ b/s$

    $1\ Gb/s = 10^3\ Mb/s = 10^6\ Kb/s = 10^9\ b/s$

    $1\ Tb/s = 10^3\ Gb/s = 10^6\ Mb/s = 10^9\ Kb/s = 10^{12}\ b/s$

    计算机网络中，带宽用来表示网络中某信道传送数据的能力，网络带宽表示单位时间内网络中的某信道所能通过的“最高数据率”，带宽单位：bit/s、b/s。

网络体系结构（OSI七层 vs TCP/IP四层 vs 五层参考模型）

OSI参考模型

​ 基于国际标准化组织(International Standards Organization,ISO)1983年开发的提案提出了OSI(Open Systems Interconnection)参考模型,并在1995年修订。

​ OSI七层模型：

层 名称 英文 功能 数据单位 典型设备/协议
7 应用层 Application Layer 为用户提供网络应用服务，用户与网络的接口 报文 HTTP、FTP、SMTP、DNS、Telnet
6 表示层 Presentation Layer 数据格式转换、加密解密、压缩解压缩 报文 JPEG、MPEG、ASCII、SSL/TLS
5 会话层 Session Layer 建立、管理和终止会话连接 报文 RPC、NetBIOS、SSL
4 传输层 Transport Layer 端到端的可靠传输、流量控制、差错恢复 数据段/报文段 TCP、UDP
3 网络层 Network Layer 路由选择、寻址、分组转发 数据报/分组 IP、ICMP、路由器、三层交换机
2 数据链路层 Data Link Layer 相邻节点间的可靠传输、帧同步、差错控制 帧 MAC、交换机、网桥、PPP
1 物理层 Physical Layer 透明传输比特流、定义电气/机械/功能特性 比特 网卡、集线器、中继器、网线

一定要把这OSI参考模型背下来！（物数网传会表应）

当主机A给主机B发送消息时，通常是：消息在主机A从上到下，传送给主机B，然后消息在主机B从下到上进行传递。

每一层之间可以通过不同通信协议来通信，只是从逻辑上来讲两个设备的层之间可以相互通信，但实际上他们依然需要从上到下或从下到上地进行传递。

服务是值一层向它的上一层提供的一组原语(操作)(一定是下一层对上一层提供服务，不能反)

OSI参考模型的问题

由于OSI参考模型推出时，TCP/IP已经广泛部署，加上其自身存在以下问题，导致OSI七层模型并没有被真正广泛应用：

问题 说明
时机错误 OSI标准制定时，TCP/IP已经在全球大面积部署，标准来得太晚
设计问题 会话层和表示层在实际应用中几乎为空，很少有独立协议对应这两层
分层过细 数据链路层和物理层划分过于复杂，物理层包含大量不同的物理介质标准
实现复杂 七层模型过于理想化，实现起来效率低，不如TCP/IP的简洁四层模型实用
TCP/IP模型

TCP/IP实际上合并了某些层级，将OSI七层模型合并为四层。

TCP/IP模型最早实现之一是作为Berkerley Unix的一部分,尤其是学术界都把TCP/IP看成是Unix的一部分。

TCP/IP模型虽然是当今互联网的实际标准，但它在设计上也存在一些问题和局限性。

问题 说明
概念不清晰 TCP/IP模型没有明确区分服务、接口和协议这三个关键概念
通用性差 TCP/IP模型是专门为TCP/IP协议栈设计的，不适用于描述其他协议栈（如蓝牙、ZigBee等）
链路层定义模糊 TCP/IP模型中的网络接口层并不是通常意义的一层，它只是一个接口（规定了如何接入网络），而真正意义上的“层”应该包含完整的协议和功能
物理层缺失 TCP/IP模型没有区分物理层和数据链路层，将两者合并为“网络接口层”。对于有线以太网可能够用，但对于无线网络、光纤等物理介质差异较大的场景，这个设计就显得不够精细
协议固化 早期自主实现的协议已经被广泛部署，导致其他协议（如IPv6）难以取代现有协议，形成“赢家通吃”的局面
五层参考模型

由于OSI七层模型过于理论化、TCP/IP四层模型又过于简化（物理层与链路层未区分），在实际教学和工程实践中，通常采用 五层参考模型 作为折中方案。

五层参考模型综合了OSI的严谨分层思想和TCP/IP的简洁实用性，是目前计算机网络教材中最常用的教学模型。

层级 名称 英文 对应OSI层 对应TCP/IP层 功能 数据单位 典型协议/设备
5 应用层 Application Layer 应用层 + 表示层 + 会话层 应用层 为用户提供网络应用服务 报文 HTTP、FTP、SMTP、DNS
4 传输层 Transport Layer 传输层 传输层 端到端的可靠传输 数据段 TCP、UDP
3 网络层 Network Layer 网络层 网络层（网际层） 路由选择、寻址、分组转发 数据报 IP、ICMP、路由器
2 数据链路层 Data Link Layer 数据链路层 网络接口层 相邻节点间的可靠传输 帧 MAC、交换机、网桥
1 物理层 Physical Layer 物理层 （未区分，合并进网络接口层） 透明传输比特流 比特 网卡、集线器、中继器

网络交换技术

有三种网络交换方式，下面详细介绍

网络交换方式

电路交换的优缺点明显

优点：

1.通信延时小，实时性强，可靠性高

2.数据可以有序传输，安全性好，实现简单

缺点：

1.建立时间长

2.线路独占，利用率低，灵活性差

优点:

1.线路利用路高，提供多目标服务

2.不用建立连接，动态分配线路

3.提高了线路的可靠性和利用率

缺点:

1.“存储-转发”实时性差

2.对报文大小无限制，存储空间大

3.发生错误时，请求重传，整个报文丢弃

优点:

  1. 存储空间开销小
  2. 无效传输低
  3. 传输延迟低

缺点:

  1. 分组乱序，各个分组可通过不同的路径达到目的站点
  2. 通信效率低

计算机网络性能度量指标

一、时延（Delay）

时延是指数据（一个报文或分组）从网络（或链路）的一端传送到另一端所需的总时间，也称为延迟或迟延。时延由以下四个部分组成：

时延类型 含义 影响因素
传输时延（发送时延） 数据从结点进入传输媒体所需的时间，即发送数据帧所需的时间 数据帧长度、发送速率
传播时延 电磁波在信道中传播一定距离所花费的时间 信道长度、信号传播速度
处理时延 主机或路由器收到分组后，为处理分组（如分析首部、提取数据、差错检验、查找路由）所花费的时间 硬件性能、路由器负载
排队时延 分组在路由器输入/输出队列中排队等待处理所经历的时延 网络拥塞程度、队列长度

总时延 = 传输时延 + 传播时延 + 处理时延 + 排队时延

二、时延抖动（Jitter）

时延抖动是指时延的变化。由于网络中的队列或缓冲区状态不断变化，分组经历的网络时延会随时间而波动，这种变化称为抖动。

时延抖动的特点：

  • 起源于网络中的队列或缓冲机制
  • 难以精确预测（受网络流量动态变化影响）
  • 对语音、视频等实时多媒体业务影响显著，抖动过大会严重影响用户体验
三、往返时延（RTT，Round-Trip Time）

往返时延是指从发送方发送数据开始，到发送方收到来自接收方的确认，所经历的总时间。

RTT的主要应用：

  • 判断网络的通断性
  • 测试网络时延
  • 计算数据包丢失率
  • TCP协议中用于超时重传时间的计算
四、吞吐量（Throughput）

吞吐量是指单位时间内通过某个网络（或信道、接口）的数据量，单位为 b/s（bit/s）。

概念 定义 说明
吞吐量 单位时间内通过某网络的数据量 反映网络的实际数据传送能力
有效吞吐量（Goodput） 单位时间内，目的地正确接收到的有用信息量 不包括重传数据、协议开销等无效数据
五、利用率（Utilization）
概念 定义
信道利用率 某信道有百分之几的时间是被利用的（即有数据在传输）
网络利用率 全网络的信道利用率的加权平均值

注意：利用率并非越高越好。当利用率接近100%时，意味着网络处于拥塞状态，排队时延会急剧增大，反而导致网络性能严重下降。

六、丢包率（Packet Loss Rate）

丢包率是指所丢失的数据包数量占所发送数据包总数的比率。

丢包率=丢失的数据包数发送的数据包总数丢包率=发送的数据包总数丢失的数据包数

丢包的主要原因：

  • 网络拥塞导致路由器队列溢出
  • 传输过程中的比特差错
  • 路由器处理能力不足
  • 链路故障
七、各指标之间的关系
指标 关联说明
时延 与 时延抖动 时延抖动是时延的变化量，多媒体业务对抖动更敏感
吞吐量 与 丢包率 当网络拥塞时，吞吐量下降，丢包率上升
利用率 与 排队时延 利用率升高 → 排队时延增大 → 总时延增大
RTT 与 时延 RTT ≈ 发送方到接收方的时延 + 接收方到发送方的确认时延

数字调制

​ 为了发送数字信息,必须设法使用模拟信号表示比特(数字信息)。比特与代表它们的信号之间的映射过程称为数字调制。

​ 模拟信号是连续的：例如连续变化的电压，光照强度，声音强度

码元：码元就是数字调制过程中用来承载信息的基本信号单位，它通过特定的映射关系，将一组比特与一个独特的信号状态对应起来，从而实现数字信息的传输。

波特率与比特率
概念 定义 单位 关注点
波特率 单位时间内传输的码元个数 波特（Baud） 物理信号的变化频率，反映底层通信速率
比特率 单位时间内传输的比特个数 bit/s（bps） 实际传输的数据量，反映有用信息的速率

波特率描述的是物理层信号波形的变化速率，即每秒钟信号状态发生变化的次数。例如，一个码元可以携带1个或多个比特的信息。当每个码元仅携带1个比特时，波特率与比特率数值相等；当每个码元携带多个比特时，比特率 = 波特率 × 每个码元携带的比特数。

比特率描述的是实际传输的有用数据速率，即每秒钟从发送端到接收端成功传输的比特数量。它反映了网络传输数据的实际效率。

$$比特率 = 波特率 \times \log_2 N$$

其中，N 为一个码元所含的状态数（即一个码元可以取 N 种不同的离散值）。

场景 波特率 每个码元比特数 比特率
二进制传输（N=2） 1000 Baud 1 bit 1000 bit/s
四电平传输（N=4） 1000 Baud 2 bit 2000 bit/s
八电平传输（N=8） 1000 Baud 3 bit 3000 bit/s
数字调制方法

将数字信号调制成模拟信号，有调幅、调频和调相三种方式。

QAM 正交振幅调制

QAM（Quadrature Amplitude Modulation，正交振幅调制）是在频率相同的前提下，将调幅（AM） 和 调相（PM） 相结合，形成叠加的调制信号。

$$\text{比特率} = \text{波特率} \times \log_2 ({相位数} \times {振幅数})$$

物理层极限容量

奈奎斯特定理

在无噪声的理想信道中，码元传输速率存在一个上限值，该上限由信道带宽决定：

$$B = 2H$$

H位信道的带宽，即信道传输上、下限频率差值，单位为Hz

无噪声下信道传输能力：

$$C = B \log_2 N \quad (\text{b/s})$$

其中：

  • C为信道传输能力（比特率），单位为 b/s
  • B为波特率（码元传输速率），单位为 Baud
  • N为码元可取的离散电平数（状态数）
香农公式

$$C = H \log_2 \left( 1 + \frac{S}{N} \right)$$

其中：

符号 含义 单位
C 信道最大传输速率（信道容量） bit/s（bps）
H 信道带宽 Hz
S 信号功率 W
N 噪声功率 W
S/N 信噪比 无量纲（倍数）
信噪比分贝

信噪比（Signal-to-Noise Ratio，SNR）是信号功率与噪声功率的比值。在工程上，信噪比通常用分贝（dB） 来表示，其换算关系为：

$$\text{信噪比(dB)} = 10 \lg \left( \frac{S}{N} \right)$$

其中，SS 为信号功率，NN 为噪声功率。分贝值常用于衡量信号质量，数值越大表示信号相对噪声越强。

信噪比（S/N） 分贝（dB） 计算过程
10 10 dB 10lg⁡(10)=10×1=1010lg(10)=10×1=10 dB
100 20 dB 10lg⁡(100)=10×2=2010lg(100)=10×2=20 dB
1000 30 dB 10lg⁡(1000)=10×3=3010lg(1000)=10×3=30 dB

信道复用技术

信道复用（Channel Multiplexing）是指在有限的物理信道资源上，通过不同方式让多个信号共享同一个信道，以提高资源利用率和通信效率。对物理信道进行复用主要有三种方法：频率、时间和编码。

常见的信道复用技术有：频分复用、时分复用、码分复用，此外还有一种称为波分复用，本质上是频分复用的光学形式。

一、频分复用（FDM，Frequency Division Multiplexing）

频分复用将信道的可用频谱划分为多个互不重叠的频率子带（频段），每个子带分配给一个独立的信号使用。信号在频域上并排分布，互不干扰。

比如收音机，同时接收各种不同的频段，通过解析不同的频率来换台。

优点 缺点
技术成熟，实现简单 频带利用率相对较低，存在保护带的开销
各信道之间隔离度高，干扰小 频谱资源固定分配，灵活性差
适合模拟信号传输 频带划分后难以动态调整带宽
二、时分复用（TDM，Time Division Multiplexing）

时分复用将时间划分为若干个等长的时隙（Time Slot），每个时隙轮流分配给不同的信号使用。信号在时间上顺序排列，互不重叠。

比如对讲机，是半双工通信，需要在不同时间内使用才能有效传递信息，即不同信号在不同时间传输。

同步时分复用 vs 统计时分复用

类型 说明 特点
同步时分复用（STDM） 每个信号源分配固定时隙，无论有无数据都占用 实现简单，但信道利用率低
统计时分复用（STDM） 时隙动态分配，仅当信号源有数据时才分配时隙 实现复杂，但信道利用率高
三、码分复用（CDM，Code Division Multiplexing）

码分复用为每个信号分配一个正交码。所有信号在同一时间、同一频率上传输，通过不同的编码序列在码域上相互区分。

就好像不同国家的学生同时在一个屋子里说话，有人在用中文，有人在用英语，有人在用法语交流…每个人只能听懂自己懂得的语言，听不懂的语言不会影响同语言交流。

码片序列（Chip Sequence）

在码分复用（CDMA）中，一比特会被再细分成多个码片（Chip）。码片是比比特更短的时间单位。

  • 每个比特由多个码片组成
  • 一个比特通常被分为 64 或 128 个码片
  • 码片序列越长，抗干扰能力越强，但占用带宽越大

在计算机网络中，每一个节点（站点）会被分配一个唯一的码片序列，用于区分不同的通信节点。

在计算机网络中，任意两个节点的码片序列是正交的，从而实现多用户共存且互不干扰

从数学角度看，所谓正交就是任意两个不同的码片归一化内积为0

码片序列的正交性：

设两个码片序列 $S$ 和 $T$ 的长度均为 $m$，若它们正交，则满足：

$$S \cdot T = \frac{S_1 T_1 + S_2 T_2 + \cdots + S_m T_m}{m} = 0$$

示例：两个码片序列 $A$ 和 $B$ 分别为

$$A = (-1 \quad -1 \quad -1 \quad +1 \quad +1 \quad -1 \quad +1 \quad +1)$$

$$B = (-1 \quad -1 \quad +1 \quad -1 \quad +1 \quad +1 \quad +1 \quad -1)$$

计算其内积：

$$A \cdot B = \frac{1 + 1 - 1 - 1 + 1 - 1 + 1 - 1}{8} = 0$$

因此，$A$ 和 $B$ 为正交码片序列。

任何码片与自身归一化内积一定为1。

码片序列的自相关性：

设码片序列 $S$ 的长度为 $m$，则其与自身的内积满足：

$$S \cdot S = \frac{S_1 S_1 + S_2 S_2 + \cdots + S_m S_m}{m} = 1$$

示例：码片序列 $A$ 为

$$A = \begin{pmatrix} -1 & -1 & -1 & +1 & +1 & -1 & +1 & +1 \end{pmatrix}$$

计算其自相关内积：

$$A \cdot A = \frac{1 + 1 + 1 + 1 + 1 + 1 + 1 + 1}{8} = \frac{8}{8} = 1$$

因此，码片序列与其自身的内积为 1。

任何码片与自身反码归一化内积一定为-1

码片序列与其反码的相关性：

设码片序列 $S$ 的长度为 $m$，$\overline{S}$ 为 $S$ 的反码（各位取反），则：

$$S \cdot \overline{S} = \frac{S_1 \overline{S_1} + S_2 \overline{S_2} + \cdots + S_m \overline{S_m}}{m} = -1$$

示例：码片序列 $A$ 及其反码 $\overline{A}$ 分别为

$$A = \begin{pmatrix} -1 & -1 & -1 & +1 & +1 & -1 & +1 & +1 \end{pmatrix}$$

$$\overline{A} = \begin{pmatrix} +1 & +1 & +1 & -1 & -1 & +1 & -1 & -1 \end{pmatrix}$$

计算 $A$ 与 $\overline{A}$ 的相关性：

$$A \cdot \overline{A} = \frac{-1 - 1 - 1 - 1 - 1 - 1 - 1 - 1}{8} = -1$$

因此，码片序列与其反码的内积为 $-1$。

码分复用中的数据恢复（解码）

在码分复用（CDMA）系统中，接收方必须预先知道发送节点的码片序列，才能正确恢复该节点发送的数据。这就是为什么每个节点都需要分配一个唯一的、已知的码片序列。

解码原理

接收端接收到的是所有节点信号的叠加信号。要恢复某个特定节点（如节点 A）发送的数据，接收端只需要：

  1. 用节点 A 的码片序列与接收到的叠加信号做内积运算
  2. 将内积结果除以码片长度进行归一化
  3. 根据结果判断节点 A 发送的是 1、0 还是静默

解码判断规则

归一化内积结果 含义
+1 该节点发送了比特 1
-1 该节点发送了比特 0
0 该节点没有发送数据（静默）

码分复用解码示例

两个节点的码片序列分别为：

$$A = \begin{pmatrix} -1 & -1 & +1 & -1 & +1 & +1 & +1 & -1 \end{pmatrix}$$

$$B = \begin{pmatrix} -1 & +1 & -1 & +1 & +1 & -1 & +1 & -1 \end{pmatrix}$$

发送数据

假设节点 A 发送比特 1，节点 B 发送比特 0：

$$\text{节点 A：} \quad A = \begin{pmatrix} -1 & -1 & +1 & -1 & +1 & +1 & +1 & -1 \end{pmatrix}$$

$$\text{节点 B：} \quad \overline{B} = \begin{pmatrix} +1 & -1 & +1 & -1 & -1 & +1 & -1 & +1 \end{pmatrix}$$

空中叠加信号

$$S_{\text{叠加}} = A + \overline{B}$$

$$S_{\text{叠加}} = \begin{pmatrix} 0 & -2 & +2 & -2 & 0 & +2 & 0 & 0 \end{pmatrix}$$

恢复节点 A 的数据

用节点 A 的码片序列与叠加信号做内积：

$$S_{\text{叠加}} \cdot A = \frac{0 + 2 + 2 + 2 + 0 + 2 + 0 + 0}{8} = \frac{8}{8} = 1$$

$$\text{归一化内积为 } +1 \quad \Longrightarrow \quad \text{节点 A 发送的是比特 1}$$

恢复节点 B 的数据

用节点 B 的码片序列与叠加信号做内积：

$$S_{\text{叠加}} \cdot B = \frac{0 - 2 - 2 - 2 + 0 - 2 + 0 + 0}{8} = \frac{-8}{8} = -1$$

$$\text{归一化内积为 } -1 \quad \Longrightarrow \quad \text{节点 B 发送的是比特 0}$$

四、波分复用（WDM，Wavelength Division Multiplexing）

波分复用是频分复用（FDM）在光纤通信中的应用，本质上是光领域的频率复用。它利用不同波长的光信号在同一根光纤中同时传输。

对比表
对比维度 频分复用（FDM） 时分复用（TDM） 码分复用（CDM） 波分复用（WDM）
划分依据 频率 时间 编码 波长
频率 各信号分属不同频带 所有信号共享同一频带 所有信号共享同一频带 各信号使用不同波长
时间 所有信号同时传输 各信号轮流传输 所有信号同时传输 所有信号同时传输

干扰分离 通过滤波器分离 通过时隙同步分离 通过相关解扩分离 通过分光/滤波分离

模块三：数据链路层（\*重点：封装成帧、差错控制、介质访问\*）

  • 点对点信道（PPP协议）： 帧格式、字节填充（面向字节） vs 零比特填充（面向比特）。
  • 广播信道（局域网）：
    • CSMA/CD（有线以太网）： “先听后发，边听边发，冲突停发，随机重发”（重点计算争用期/最短帧长）。
    • CSMA/CA（无线局域网）： 隐蔽站问题与RTS/CTS握手。
  • MAC地址与ARP协议： ARP是IP到MAC的映射（问：ARP在哪一层？ 答：介于数据链路层和网络层之间）。
  • 交换机组网： 透明网桥的自学习算法（转发表怎么建立的）。

模块四：网络层（\*绝对C位，难点在IP和路由\*）

  • IP地址（灵魂）： 分类地址（A/B/C） -> 子网划分（子网掩码） -> CIDR（无分类编址，最重要）。
  • 核心计算： 给定IP和子网掩码，求网络地址、广播地址、可用主机数（必考大题）。
  • 路由协议（区分内外部网关）：
    • RIP（距离向量）： 好消息传得快，坏消息传得慢（计数到无穷），基于UDP。
    • OSPF（链路状态）： 迪杰斯特拉算法，收敛快，基于IP直接封装。
  • ICMP协议： Ping（回送请求）和 Traceroute（时间超时）。

模块五：传输层（\*区分UDP和TCP是核心\*）

  • UDP： 无连接、不可靠，但头小（8字节），用于DNS、SNMP。
  • TCP（重头戏）：
    • 报文段格式： 重点记标志位（SYN=1, ACK=1, FIN=1）和序号确认号机制。
    • 三次握手（建立）： 为什么是3次？（防止过期连接请求突然到达）。
    • 四次挥手（释放）： 为什么是4次？（因为被动关闭方可能还有数据要发），以及 TIME_WAIT 的必要性。
    • 流量控制（滑动窗口）： 接收端控制发送端速度。
    • 拥塞控制（必考大题）： 慢开始、拥塞避免、快重传、快恢复（画图判断拥塞窗口变化）。

模块六：应用层（\*典型协议速记\*）

  • DNS（域名解析）： 递归查询 vs 迭代查询。
  • HTTP（万维网）：
    • 非持久连接 vs 持久连接（有无流水线）。
    • Cookie/Session 如何保持状态（HTTP无状态）。
    • HTTPS = HTTP + SSL/TLS（加密）。
  • FTP： 控制连接（21）和数据连接（20，主动/被动模式）。
  • 电子邮件： SMTP（推） vs POP3/IMAP（拉）。
